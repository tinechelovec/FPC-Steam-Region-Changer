# Steam Region Changer — инструкция

Steam Region Changer — плагин для **FunPay Cardinal**, предназначенный для смены региона Steam.

> [!IMPORTANT]
> Используйте плагин только с новыми Steam-аккаунтами без пополнений, покупок, активированных ключей и уже закреплённой валюты.

## 📦 Установка и обновление

1. Скачайте файл плагина из [GitHub-репозитория](https://github.com/tinechelovec/FPC-Steam-Region-Changer).
2. Откройте Telegram-бота Cardinal.
3. Перейдите в **Плагины → Добавить плагин**.
4. Отправьте скачанный файл **Steam Region Changer**.
5. После установки обязательно выполните команду `/restart`.

## ⚙️ Главное меню

В панели настроек доступны три основных раздела:

- **Настройки плагина** — основные параметры работы.
- **Настройка лотов** — добавление и редактирование лотов.
- **Статистика** — статистика работы плагина.

![Главное меню](https://img1.teletype.in/files/8f/93/8f93f155-0600-4376-a00b-8858571e78df.png)

## 🛠 Настройки плагина

Здесь можно включить или отключить плагин, настроить обработку заказов, уведомления, очередь и лимиты, работу с гифтами, а также открыть раздел обслуживания с логами и конфигами.

![Настройки плагина](https://img4.teletype.in/files/37/a0/37a067b8-2ea9-4a8c-af74-0b66b7d0472b.png)

## ⭐ Настройка лотов

Лоты можно добавить автоматически или вручную. Нажмите на нужный лот, чтобы изменить его параметры.

![Список лотов](https://img2.teletype.in/files/5f/84/5f84e1c4-cb45-4b7a-a8db-0b4e7c947979.png)

Для каждого лота доступны:

- включение и отключение;
- выбор целевой страны;
- добавление прокси;
- удаление лота.

> [!WARNING]
> Для смены региона требуется прокси нужной страны.

![Настройки лота](https://img2.teletype.in/files/1d/30/1d30cce7-fe11-45dc-95b4-82285611c67a.png)

## 🗑 Удаление плагина

Откройте карточку **Steam Region Changer** в списке плагинов и нажмите **Удалить**.

![Удаление плагина](https://img1.teletype.in/files/46/18/461896eb-295e-4ff8-bc1d-932646fda556.png)
